# Contributing to Hardhat's website

Thanks for your interest in contributing to Hardhat's website!

You can start by reading the [Starlight](https://starlight.astro.build) documentation, and modifying any content in the [`src/content`](./src/content) directory.

## Running the website locally

To run the website locally, you'll need to install the dependencies:

```bash
pnpm install
```

Then, you can run the development server:

```bash
pnpm run dev
```
